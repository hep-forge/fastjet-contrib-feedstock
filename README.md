[![Build AMD64](https://github.com/hep-forge/fastjet-contrib-feedstock/actions/workflows/autoupload.amd64.yml/badge.svg)](https://github.com/hep-forge/fastjet-contrib-feedstock/actions/workflows/autoupload.amd64.yml)
[![Build ARM64](https://github.com/hep-forge/fastjet-contrib-feedstock/actions/workflows/autoupload.arm64.yml/badge.svg)](https://github.com/hep-forge/fastjet-contrib-feedstock/actions/workflows/autoupload.arm64.yml)

Feedstock for [fastjet-contrib](https://fastjet.hepforge.org/contrib/) — part of [hep-forge](https://anaconda.org/hep-forge).

The fastjet-contrib space is intended to provide a common location for access to 3rd party extensions of FastJet.

## Install

```bash
conda install -c hep-forge -c conda-forge fastjet-contrib
```
